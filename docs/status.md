## 満たしていない要件を妨げているもの

### 2: Python と Node の本体の patch の自動マージ

本体の版を上げる PR には、App が push したコミットが入ります。正本への写しか、セキュリティの修正の PR そのものです。
main の規則は「最後に push した本人以外の承認」を求め、自分が出した PR の承認も認めません。同じ App の承認では通りません。
書き込む App と承認する App を分けると、通る見込みです。まだ試していません。

### 9: セキュリティ更新の自動マージの確認

古いセキュリティ更新の PR は、壊れていたので閉じました。Dependabot が出し直すのを待っています。

### 11: 手元の uv

uv の版を 1 点に固定する設定（`required-version`）を書くと、Dependabot の uv の更新が失敗します。
手元の版を揃えるには、版を管理する道具（mise など）の設定ファイルを足す形になります。まだ入れていません。
